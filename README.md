# jsn-Storage

マイクラ（NeoForge 1.21.1）の、ランクつきのチェスト・シュルカーボックス・リュック。

- **5ランク**：木（リュックは革）→ 鉄 → 金 → ダイヤ → ネザライト。マスとアップグレードの枠が増える。
- **強化キット**：置いてあるチェスト・シュルカーを右クリックで、中身はそのまま1つ上のランクに。鉄のキットはふつうのチェスト・シュルカーにも使える。リュックは作業台でキットといっしょに。
- **リュック**：右クリックで開く。Curios の「背中」の枠につけて B キーでも開ける。
- **並べ替え**：画面の右上のボタン（種類・名前・数）。
- **アップグレード**：左の枠に入れて、右クリックで設定。多くは銅・金・ダイヤの3ランク。
  - 容量アップ（2倍・4倍・8倍）
  - 自動で拾う（登録した物だけ。ほかの人が落とした物は拾わない）
  - いらない物を消す（登録した物だけ）
  - 自動で食べる（登録した食べ物だけ。リュック）
  - 補充（手のブロック、金で矢、ダイヤでこわれそうな道具の交換。リュック）
  - 経験値貯蔵・マナ貯蔵・スタミナ貯蔵（マナとスタミナは jsn-Craft が必要）
